# Hand-written prose for rule pages

A file here named after a rule's page, such as `min-wall-thickness.md` for
`content/reference/rules/min-wall-thickness.md`, is placed on that page under the rule's diagram
by `docs/build.py`. Use it for what the code can't say: how the rule is checked, and how to fix a
finding. Start its headings at `##`. Don't repeat values: the page shows them.
