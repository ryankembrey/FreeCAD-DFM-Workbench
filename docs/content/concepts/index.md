# Concepts

A few ideas run through the whole workbench. Knowing them makes the results and the Process Library
easier to read.

- [Aim for and limits](aim-for-and-limits.md): most rules have two values, one to design for and one
  you must not cross. Which one a measurement crosses decides between a warning and an error.
- [Criticality](criticality.md): how much a rule matters to a process, which decides how the
  results are sorted.
- [Nominal wall](nominal-wall.md): the thickness most of a molded part's walls share, which many
  molding rules are measured against.
- [Feature recognition](feature-recognition.md): how the workbench finds holes, bosses, ribs and
  other features in your part.
- [Pull and print directions](directions.md): the direction the mold opens or the part prints,
  and how to set it.
