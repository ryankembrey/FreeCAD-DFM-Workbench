# How we cite

The workbench's values come from design guides published by manufacturers, material suppliers and
printer makers. This section shows where each value comes from, so you can check it, and so you can
decide how far to trust it.

Every value on the rule pages carries one of these:

| Kind | Meaning |
| :-- | :-- |
| **Published** | A source gives this figure. Unit conversions and rounding are allowed, and the original figure is in the note (hover over the source's name). |
| **Derived** | Worked out from a source's figures, for example 60% of a published limit. The note says how. |
| **Engineering judgement** | No source gives a figure, so the value is our judgement. Where a source gives the advice without a number, it is named. |
| **Not yet sourced** | The value came from a source, but which one hasn't been recorded yet. |

A material that doesn't set a value uses the Default material's value, and its source.

- [Coverage](coverage.md) lists every value and its source, process by process.
- [The bibliography](bibliography.md) lists every source, with links where they have been recorded.

!!! tip "Your values come first"

    Design guides differ, and so do machines and material grades. If your supplier or printer gives
    different figures, use theirs: change the values in the Process Library.
